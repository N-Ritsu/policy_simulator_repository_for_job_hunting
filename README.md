# 政策シミュレーションゲーム 設計資料

日本の政策担当者になり、30年間、毎年「政策」を自由記述で入力していく、テキストベースの政策シミュレーションゲームの設計資料です。
プレイヤーが書いた政策の効果を、生成AI(GPT / Gemini / Claude)が評価し、ゲーム側のエンジンが50個あまりの社会指標へ反映します。

このリポジトリには**設計資料だけ**を置いています。実装コードは含みません(別の非公開リポジトリで開発しています)。

## ゲームの概要

- **2つのモード**: バブル期モード(1988年開始、「バブル崩壊を防げ!」)と、現代モード(2000年開始、「不況を跳ね除け再び技術大国へ」)。どちらも30年間。
- **社会指標**: GDP・税収・出生率・国民満足度・健康寿命・技術競争力など51個。初期値は公的統計に基づく実データ(統計化できないものは推定値)。
- **政策入力**: 毎年、自由記述で政策を入力。AIが「良い影響」「悪い影響」を、効果の出る時期・続く期間・大きさ・恒久的か一時的かをつけて評価し、エンジンが各指標に反映する。
- **レポート**: 政策ごとに、時代背景・政策の内容の分析・抵抗と副作用・諸外国の反応・総括を、当時の空気が伝わる報告調で表示。
- **史実イベント**: 諸外国の出来事と自然災害を台本化。諸外国の出来事は、この世界線で史実どおり起きるかをAIが判定する。
- **勝敗**: クリア判定は30年後のみ。指標が破綻ラインを越えたら、その時点でゲームオーバー。

## このプロジェクトで工夫した点

- **AIの評価とゲームの計算の分離**: AIには「政策が指標をどう動かすか」だけを構造化出力(JSON Schema)で評価させ、年ごとの変化量の計算、史実の趨勢(出生率の低下など)の加算、勝敗判定はエンジン側が担う。
- **3社共通のスキーマ**: OpenAI・Gemini・Claudeの構造化出力すべてで通るスキーマを設計し、同じ条件でモデルを比較できる。
- **過去の政策と現在の状況の反映**: 過去の政策・進行中の効果・指標の推移をAIに毎回渡し、飽和や二重計上を避けた評価をさせる。
- **相乗効果のルール化**: AIには政策の目的と手段を選択肢から分類させるだけにし、過去の政策との相乗効果・重複・矛盾・引き締めすぎはエンジンが組み合わせ表で決める。同じ組み合わせなら必ず同じ結果になり、理由をプレイヤーに示せる(AIの直接判断と比較検証したうえで採用)。
- **API料金の削減**: 出力項目・プロンプトを整理し、実測で1ターンあたりの料金を約6割削減。
- **実データでの調整**: 実際のAI出力から効果の形を再現したシミュレーションで、クリア条件の難易度を調整。
- **時代考証**: 「当時の経済規模に対する比率で評価する」「後知恵を使わない」という前提をAIに与える。
