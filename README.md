# 政策シミュレーションゲーム 設計資料

日本の政策担当者になり、30年間、毎年「政策」を自由記述で入力していく、テキストベースの政策シミュレーションゲームの設計資料です。
プレイヤーが書いた政策の効果を生成AIが評価し、ゲーム側のエンジンが67個の社会指標へ反映します。

このリポジトリには**設計資料だけ**を置いています。実装コードは含みません(別の非公開リポジトリで開発しています)。

## ゲームの概要

- **2つのモード**: バブル期モード(1988〜2017年、「バブル崩壊を防げ!」)と、現代モード(2025〜2054年、「人口減少の時代を乗り越え、再び技術大国へ」)。
- **社会指標**: GDP・税収・出生率・国民満足度・内閣支持率・健康寿命・技術力・人材の過不足など67個。初期値は公的統計に基づく実データ(統計化できないものは推定値)。
- **政策入力**: 毎年、自由記述で政策を入力。AIが1回の入力を1〜5件の政策に分け、「良い影響」「悪い影響」を、効果の出る時期・大きさ・恒久的か一時的かをつけて評価する。税・ODA・家計への給付・防衛費など金額で決まる量は、AIが金額を書き、エンジンが計算する。施行すると、年の移り変わり・政策の総評(AIが5種類から選ぶ)・その年の出来事を専用の画面で見せてから、報告書に進む。
- **ゲーム側の計算**: 税目ごとの税収、潜在成長率と景気の山谷、財政(フリーキャッシュ・国債)、指標どうしの連動、限界に近いほど伸びにくくなる仕組み、過去の政策との相乗効果(組み合わせ表)を、エンジンが毎年計算する。
- **出来事**: バブル期は史実の出来事90件、現代モードは100件の候補からの抽選。起きるか・避けられるか・大きさは、AIではなく社会指標で決まる。指標が節目を超えたときの出来事(記念・隠しイベントを含む)もある。
- **勝敗**: 難易度(5段階)を選び、6つのクリア条件(3つは固定、3つはくじ)を30年後に満たせばクリア。破綻ラインを越えたらゲームオーバー。
- **記録とランキング**: 30年を終えたゲームの値を記録名鑑・ランキングに残す。戻りの時計(1年の取り消し)を使っていない記録には★。
- **公開**: Googleログイン、ゲームごとのセーブデータ、毎日回復する無料枠と、回数パック・毎日30回パスの購入(Stripe)。指標ごとの政策案と「おすすめの政策」のボタン、報告書のコピー。

## このプロジェクトで工夫した点

- **AIの評価とゲームの計算の分離**: AIには政策の中身で決まる「最初の一歩」だけを構造化出力(JSON Schema)で書かせ、指標の値だけで決まる仕組みと、金額で決まる量はエンジンが計算する(二重計上を防ぎ、結果の理由を示せる)。
- **相乗効果のルール化**: AIには政策の目的と手段を選択肢から分類させるだけにし、過去の政策との相乗効果・重複・矛盾はエンジンが組み合わせ表で決める(AIの直接判断・文のベクトル化と比較したうえで採用)。
- **出来事を指標で決める**: 出来事の発生・回避・大きさを指標から計算し、「耐災害指数60により被害は52%に軽減」のように理由を示す。
- **難易度をダミープレイで調整**: 実際のAIの評価を使い回した数千ゲームのダミープレイで、どのクリア条件の組み合わせでも同じ難易度なら同じくらいの難しさになるよう目標を決める。
- **API料金の削減**: プロンプトの固定部分のキャッシュ、出力の整理などで、1ゲームあたり約6〜12円。
- **時代考証**: 「当時の経済規模に対する比率で評価する」「後知恵を使わない」という前提をAIに与える。
