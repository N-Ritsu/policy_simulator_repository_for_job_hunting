難易度とクリア条件
==================

ゲーム開始時に難易度を5段階から選ぶ。難易度は、30年経過時点のクリア条件(目標の水準)を決める。
敗北条件(破綻ライン)は、難易度によらず同じ。36で実装した(game/difficulty.py)。

■ 1. 難易度の考え方
  very easy : 史実より少し下の水準。何もしなくても、ほぼクリアできる
  easy      : 史実と同じ水準。史実より悪くしなければクリアできる
  normal    : 史実+α。初めての人でも、筋の良い政策を続ければクリアを目指せる
  hard      : 歴史や政治に詳しく、社会指標の動きを読める人がクリアを目指せる
  very hard : ほぼ理論値。何度もゲームを繰り返し、このゲームでの最強の政策を編み出した人向け
- 「史実」は、バブル期は2017年の史実(ゲームでは、政策なしで史実どおりに進んだ道筋。国の債務残高だけは史実の値)、
  現代モードは政策なしで進んだ場合の推計(出来事はランダムなので、多くのゲームの中央値)。
- 目標の水準 = 史実 + 割合 × (理論値 − 史実)
    very easy −15%(現代モードは−25%)/ easy 0 / normal 25% / hard 60% / very hard 90%
  理論値は、3.の探索で見つけた最も良い結果。目標はきりの良い値に丸めた(very easy・easy は達成しやすい側に)。

■ 2. クリア条件の指標(30年経過時点で、すべて満たす)
- バブル期: GDP、失業率、国の債務残高のGDP比、国民満足度指数、株価指数、出生率
- 現代モード: 技術力の首位との差、デジタル化指数、GDP、国民満足度指数、国の債務残高のGDP比、出生率
- 以前の仮の条件からの変更:
  - 国の債務残高は、額ではなくGDP比で見る。政策で経済が大きくなれば、借金の額が増えても重さは変わらないため
    (ダミープレイで、現代モードで積極的に政策を打つと、額は政策なしの1.7倍になったが、GDP比はほぼ同じだった)。
  - 「30年目の成長率」は外した。その年の出来事で大きく振れ、30年の運営の結果を表さないため(成長の結果はGDPで見る)。

■ 3. 理論値の求め方
- 実際のAI(gpt-5.6-luna)で、各モード10の政策を評価した(API呼び出し20回)。
  初見(初めての人が書きそうな、短く一般的な政策)4つと、詳しい人の具体的な政策6つ。
  バブル期: 公共事業 / 子育て手当 / 消費税3%の導入 / 研究開発(以上、初見)、バブルの軟着陸(総量規制・地価税) /
            不良債権の早期処理と公的資金 / 少子化対策の一体の推進 / 新産業の成長戦略 / 歳出の上限と国債の償還 /
            労働時間の短縮と内需の拡大
  現代モード: AI・半導体への集中投資 / 子育て支援の拡充 / 消費税5%への減税 / 行政のデジタル化(以上、初見)、
            研究開発費の年5兆円上乗せ / 半導体・データセンター・脱炭素への投資と電力の安定供給 / 人口対策の一体の
            推進 / 行政の完全オンライン化と企業のデジタル投資減税 / 高度外国人材の受け入れ倍増 / 財政健全化
- 評価を年をまたいで使い回し、30年の予定表(毎年、10の政策のどれか1つか、何もしない)を作って探した。同じ政策は
  1ゲームで3回まで(同じ政策の繰り返しで、毎年の継続出費などが積み上がりすぎないように)。
- 探し方: でたらめな予定表150通りから始め、1か所を入れ替える・2か所を交換する山登りを1,200〜1,500回。点数は
  「各指標の伸び(史実との差を、指標ごとの目安の幅で割った値)のうち、最も小さいもの」(全指標をバランスよく伸ばす
  予定表を選ぶ)。現代モードは、乱数の種6通りの中央値で比べた。
- 最も良い予定表の結果(30年後。現代モードは、探索に使っていない乱数の種40通りの中央値):
    バブル期: GDP 878兆円、失業率1.96%、債務残高のGDP比23%、国民満足度74.4、株価指数336、出生率2.24
    現代モード: 技術力の首位との差+68、デジタル化指数97、GDP 1,083兆円、国民満足度77.6、債務残高のGDP比183%、出生率2.30

■ 5. 確かめたこと(遊び方ごとのクリア率。実際のAIの評価を使い回したダミープレイ)
  遊び方                               very easy  easy  normal  hard  very hard
  バブル期
    政策なし                             100%     100%    0%     0%     0%
    初見(初見の4政策を、順番をばらして)  100%     100%    0%     0%     0%
    筋の良い政策(10の政策をばらばらに)   100%     100%   75%     0%     0%
    最も良い予定表                        100%     100%  100%   100%   100%
  現代モード(乱数の種40通り)
    政策なし                              75%      35%    0%     0%     0%
    初見                                  35%      16%    3%     0%     0%
    筋の良い政策                          89%      77%   51%    21%     0%
    最も良い予定表                        100%     100%  100%   100%    70%
- 初見の遊び方が現代モードで伸びないのは、消費税の減税(10%→5%)を繰り返して税収が大きく減り、債務残高のGDP比が
  約340%まで膨らむため(財政を考えずに政策を打つと、低い難易度でも落とす)。バブル期は好景気の税収で余力があり、
  国債はほとんど増えない。
- 現代モードでは出来事がランダムなので、同じ遊び方でもクリアできるかどうかが変わる(最も良い予定表でも very hard は
  7割)。何度も挑戦して、出来事に合わせて政策を変える人向け、という位置づけに合う。

■ 6. 気づいたこと・課題
- AIの評価の誤り(修正した): バブル期の「軟着陸」(総量規制・地価税)を、AIが「地価の安定」として地価指数の良い影響
  (=地価が上がる)に書いた。地価は上がるのが良いとは限らないので、プロンプトの指標の一覧に「地価を下げる政策は
  negative_impacts に『地価の下落』として書く」と注記した。難易度の調整では、この評価の地価の影響を下落に直して使った。
  37で実際のAIで確かめた(5回): 注記の後は、軟着陸・総量規制・地価税のいずれも地価を negative(下落)に書き、
  地価に関係のない工場誘致では地価を書かなかった。同じ評価で、株価にも同じ誤り(「金融市場の過熱を抑制」を株価の
  良い影響=株価が上がる、に書いた)があったので、株価指数にも同じ注記を足し、注記の後は「株価の過熱を冷却」として
  negative(一時的)に書くことを確かめた。
- 現代モードは、政策を積極的に打つとGDP・技術力・出生率が大きく伸びる(10の政策をばらばらに使うだけで、30年後の
  GDPが政策なしの約1.8倍、出生率2.3、技術力の首位との差+55)。そのため、難易度を分けるのは主に債務残高のGDP比に
  なっている。政策の効果の強さ(特に同じ分野の政策を何度も打ったときの伸び)は、実際のプレイで確かめ、必要なら
  別に見直す。
- バブル期は、開始時の財政の余力(毎年約10兆円の黒字)が大きく、どの遊び方でも国債はほとんど増えない。
  債務残高の条件は、極端な出費をしたときだけ効く。
- ダミープレイは、評価を年をまたいで使い回している(実際には、AIの評価はその年の状況で変わる)。目標の水準は、
  実際のプレイの結果を見て微調整する。
- 以前に話した「今後の出来事の予告」(難易度によって見せる)は、今回は入れていない。
