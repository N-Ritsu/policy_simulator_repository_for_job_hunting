117 チュートリアルの段階の切り替えを画面の側だけで行い、待ち時間をなくす・指す場所と画面の移動を直す
===============================================

■ 基本情報
- コミット: ad3f7b5
- 日付: 2026-10-26
- メッセージ: Switch tutorial steps in the browser and lock navigation during the tutorial

■ 概要
ユーザーの依頼・質問:
- 遊び方の4・5・6段階目の指し方がおかしい。
- 年が進むとき(バブル期1年目 → 2年目の画面)に、上の切り替えから「新しいゲーム」「記録名鑑」などに移れてしまう。
- チュートリアルを進めるたびに1秒ほど読み込み時間がかかる。Streamlit だと避けられないのか。
  → Streamlit は、ボタンを押すたびにサーバーで画面全体を描き直すので、サーバーのボタンを使う限り避けられない。
    段階の切り替えを画面の側(ブラウザ)だけで行えば避けられるので、そうした。

■ 変更内容
1. game/tutorial_js.py(新規): 画面の側でチュートリアルを動かす JavaScript。段階の絵・言葉・何段階目か・ボタンの状態の
   入れ替え(render)、次へ・戻る・スキップ(act)、場所に合わせた札・指示棒・明るい枠(place。116と同じ考え方)、
   なめらかなスクロール(go)、札がなくなったときの後片付け(見張り)、ボタンの押下・スクロールの停止・位置の合わせ直しを
   ページに一度だけ付ける処理。サーバーが段階を決め直した回数(epoch)が同じなら、描き直されても画面の側の段階のまま続ける。
   下いっぱい(スマホ)と右下のときは、指示棒を110pxまでにする。
2. app.py
   - render_tutorial: 札は最初の表示だけサーバーで描き、設定(段階・最初の段階・epoch・絵)と担当の JavaScript を、
     iframe からページの側に <script> として差し込む。隠したサーバーのボタン tut_srv_run(例の政策の段階に入る。入力欄に
     例の政策を入れる)と tut_srv_end(閉じる。見終えた印を残す)を置く。
   - サーバーの「次へ・戻る」(_tutorial_move)をなくし、_tutorial_set(段階を決め直し、epoch を進める)と
     _tutorial_go_run を足した。
   - 4段階目は入力欄そのもの(.st-key-policy_input)、6段階目は施行のボタン(.st-key-run_policy)を指す。
   - チュートリアルのあいだは、上の切り替えを押せなくし(disabled)、サイドバーを暗くして押せなくする(どの画面でも)。
3. game/ui_theme.py: tutorial_html を、HTML のボタン(戻る・スキップ・次へ)付きの札に変えた。ボタンの見た目、隠した
   サーバーのボタンの置き場、例の政策の段階の見た目を body.tut-run で切り替える CSS。
4. README・判断の記録/04 を直した。

■ 検討した案と判断
【比べた案】 - 待ち時間: そのまま / 札だけを Streamlit の fragment で描き直す / 画面の側の JavaScript だけで切り替える
【決め手】 fragment にすれば描き直すのは札だけになるが、サーバーとの往復は残る。画面の側で切り替えれば待ち時間がなくなる。
          サーバーが本当に要るのは、例の政策を入力欄に入れるときと、見終えた印を残すときだけなので、そのときだけ
          隠したボタンを押す。担当の JavaScript をページの側で動かすのは、iframe の関数で付けた処理が、iframe がなくなると
          呼ばれなくなるため(116で分かったこと)。
【決めた人】 ユーザー(待ち時間をなくしたい)。作り方はClaude。

■ 確かめたこと
- アプリ内のブラウザ(確認用のサーバー。APIは呼んでいない。幅1440・高さ900)で:
  - 札の「次へ」を実際に押すと、すぐに「遊び方 2 / 9」に変わり、サーバーの描き直しは起きない。
  - 指示棒の先: 4段階目は入力欄の右の縁(914, 266)、5段階目はおすすめの政策のボタンの右の縁(597, 240)、6段階目は
    施行のボタンの右の縁(914, 240)に来る。
  - 初めてのとき: 8段階目に入ると入力欄に例の政策が入り、「次へ」が隠れ、施行のボタンだけ押せる。押すと年が進むときの
    画面になり、上の切り替えはすべて押せず、サイドバーも押せない。「報告書を読む」のあと9段階目(「戻る」は押せない)から
    13段階目まで進め、「はじめる」で閉じると、上の切り替えとサイドバーが元に戻る。無料枠は5回のまま。
  - スマホの幅: 札が下いっぱいに出て、指示棒は110pxで入力欄の方を向く。
  - サーバーのエラーはなかった。
