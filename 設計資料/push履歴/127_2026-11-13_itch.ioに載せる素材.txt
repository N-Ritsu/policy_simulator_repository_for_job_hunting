127 itch.io に載せる素材
===============================================

■ 基本情報
- コミット: ed66361
- 日付: 2026-11-13
- メッセージ: Add itch.io listing assets

■ 概要
ユーザーの依頼: itch.io とふりーむ! に投稿したい。やり方を教えて → 素材を全部用意してほしい。
ふりーむ! は、規約(ブラウザゲームは HTML5 のファイルのアップロードのみ、他のサーバーとの通信・ログイン・課金・外部への
誘導は不可)により今の作りでは載せられないと伝えた。itch.io 用の素材をそろえた。

■ 変更内容
1. marketing/itch_io/(新規)
   - launch/index.html と policy_sim_itch.zip: itch.io の HTML のゲームとしてアップロードする「遊ぶ」ボタンのページ。濃紺と金、
     ゲームの秘書(にこにこの顔)、題名・一言・紹介・「▶ ゲームを遊ぶ」(ゲームを新しいタブで開く)、英語の一行。
     スマホの幅では縦に並ぶ。
   - cover_630x500.png: カバー画像(itch.io のおすすめの大きさ)。題名・一言・年が進むときの画面の写真・秘書。
   - screenshots/01〜06: 1280x720 のスクリーンショット(タイトル画面・政策の起案・年が進むときの画面・審議官の報告書・
     指標のカード・推移のグラフ)。
   - itch_page.md: itch.io で入力する内容(プロジェクトの設定・アップロードの設定・紹介文(日本語と英語)・タグ・
     AI の使用の申告・公開前の確かめ方)。
2. README のディレクトリ構成と、判断の記録/05(16.)を直した。

■ 作り方(作業用のファイルは一時フォルダ。リポジトリには入れていない)
- スクリーンショット: 撮影用にアプリの写しを別のポート(8507)で動かし(開発者モード・テスト用のアカウント・撮影用の
  データベース・保存してある実際のAIの評価を返すふりのサーバー。APIは呼んでいない)、Playwright で操作して撮った。
  開発者向けの表示(管理者の切り替え・開発者モードの表示・AIの生データ)は隠し、サイドバーは閉じた。テスト用の
  アカウントは、チュートリアルとお知らせを見終えたことにしておいた。
- 途中で直したこと:
  - ふりのサーバーは、依頼の中に最初に出てくる保存してある政策の文で評価を選んでいたため、これまでの政策(依頼に一緒に
    入る)の評価を返し、報告書の中身が施行した政策と食い違った。いちばん後ろに出てくる(今回の入力の)政策で選ぶようにした。
  - 保存してある評価は1988年に評価したものなので、3年目に施行すると報告書の文が「1988年の日本では」になった。報告書を
    撮る政策は1年目に施行し、指標とグラフは何年か進めてから撮るようにした。
  - 管理者の切り替えを隠すと、設定のボタンの右端の枠が消えたので、枠と角の丸みを写した。
  - 一時フォルダの掃除で、以前の撮影に使った Python の環境が壊れていたので、作り直した。

■ 検討した案と判断
【比べた案】
  - itch.io の載せ方: ゲームをページの中に埋め込む / 「遊ぶ」ボタンで新しいタブで開く / 紹介文にリンクだけ書く
  - ふりーむ!: 載せる / 載せない
【決め手】
  - 埋め込むと Google のログインが枠の中で動かないおそれが高い。リンクだけのページは itch.io で勧められていない。
    HTML のゲームとして「遊ぶ」ボタンのページを載せ、新しいタブで開く形にした。
  - ふりーむ! は、規約で外部のサーバーとの通信・ログイン・課金・外部への誘導が認められず、今の作りでは載せられない。
【決めた人】 ユーザー(素材を全部用意する)。載せ方・素材の中身はClaude。

■ 確かめたこと
- スクリーンショット6枚を目で見て、報告書の中身と施行した政策・年が合っていること、開発者向けの表示が出ていないことを
  確かめた。
- 「遊ぶ」ボタンのページを 800x500(itch.io の埋め込みの大きさ)と 420x640(スマホ)で表示し、崩れないことを確かめた。
- zip の中身が index.html だけであること。
- itch.io の中で新しいタブが開くかは、ユーザーが下書き(Draft)の状態で確かめる(itch_page.md の 4.)。
