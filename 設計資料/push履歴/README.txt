push履歴(変更の記録)
====================

GitHubへpushするたびに、「今回のpushで何をどう変えたか」をこのフォルダに1ファイル書き起こす。
コミットメッセージ(英語・要点のみ)より詳しく、設計判断の理由や動作の変化を日本語で残すのが目的。

ファイル名: NN_YYYY-MM-DD_内容.txt
  NN  ... pushの通し番号(00から)
  日付 ... そのコミットの日付(日本時間)

各ファイルの構成:
  1. 基本情報(コミットID・日付・コミットメッセージ)
  2. 概要(何のためのpushか)
  3. 変更内容(何をどう変えたか。動作・ルール・数値の変化)
  4. 変更ファイル
  5. 補足(確認した内容・既知の課題・次にやること)
