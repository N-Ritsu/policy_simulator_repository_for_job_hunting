05 レポート形式・初期値の実データ化・史実の趨勢の規定値加算
==========================================================

■ 基本情報
- コミット: (このpushで作成。IDはgit logを参照)
- 日付: 2026-09-20
- メッセージ: Add policy reports, real initial data and historical baseline trends

■ 概要
3つの変更をまとめてpushした。
 (A) 政策の総評を、時代背景・政策の内容・抵抗と副作用・諸外国の反応を含むレポートにした。
 (B) 仮置きだった初期値を実データに置き換え、そのうえで、史実の趨勢(何もしなくても起きる変化)を
     エンジン側の規定値として毎年加えるようにした。
 (C) (B)に合わせて、政策の基準量とクリア条件を調整した。

■ 変更内容
(A) レポート形式
1. 起きていた課題
   - 総評が「政策を事務的に評価しているだけ」で、ゲームらしさが薄かった。
2. 対応
   - policy_evaluation スキーマに 4項目を追加:
       era_background(時代背景) / policy_details(政策の内容の分析、項目ごと) /
       resistance_and_side_effects(抵抗と副作用) / foreign_reactions(諸外国の反応)
     overall_review は「総括」(2〜3文)として最後に出力。次年度以降の履歴には、この短い総括だけを使う。
   - プロンプトに書き方を指定: 当時の空気や現場が伝わる報告調。金額は当時のGDP・税収比で示す。
     政策が小さい場合は短くてよい。国際的に注目されない政策では、無理に大きな反応を作らない。
     後知恵は使わない。指標は英字キーでなく日本語名で書く。
   - 画面: 「シミュレーション結果:○年末〜○+1年(バブル期/低成長期n年目)への影響」の見出しで
     各セクションを表示。過去のレポートは「過去の政策レポート」に折りたたみ表示。
   - simulation.py に PolicyReport を追加(政策ごとのレポートを保持)。
3. 新規スキーマ項目も、3社共通のstrict対応(additionalProperties:false、全項目required)。

(B) 初期値の実データ化と史実の趨勢
1. 初期値の実データ化
   - これまで中央値などで仮置きしていた約26指標(両モード合計)を、公的統計に基づく値に置き換え。
     出典: 厚生労働省、総務省、農林水産省、世界銀行、JNTOなど。
   - 数値の定義は game/indicators.py の各辞書の上のコメントに記載
     (例: 教育水準=大学・短大進学率、観光指数=訪日外客数÷3,000万人、
      特許出願指数=居住者出願数÷2000年の件数×100、輸出競争力=世界の財輸出シェア×6、
      精神的健康=100×(1−自殺死亡率/40))。
   - 概数にとどまるもの: 開業率、労働時間、犯罪発生率、パソコン普及率、国民満足度、
     健康寿命(1988年)、婚姻率。
   - 統計化できず推定値としたもの: 社会流動性(中立値50)、外交影響力、防衛力。
   - 全50指標の初期値の明示を必須にし、中央値での自動補完(_fill_defaults)を廃止。
   - あわせて直した既存の不備:
       外貨準備高: 値は「十億ドル」なのに単位が「兆円」だった → 単位を直し、実際の値(98/362)に。
       1988年の消費税: 3%と入っていたが導入は翌年 → 0%に。
       犯罪発生率: 範囲0〜300に実際の値(約1,300〜1,900)が収まらなかった → 範囲を広げた。
2. 史実の趨勢の規定値加算(game/baselines.py を新規追加)
   - 出生率・総人口・高齢化率・生産年齢人口比率・婚姻率・平均寿命・健康寿命・
     医療費対GDP比・肥満率・食料自給率の10指標に、史実の年次系列(アンカー年の実績値、間は線形補間)を持たせた。
   - エンジンは毎年「次の年の値−その年の値」を、AIが評価した政策効果に足して指標を更新する。
       例: AIが出生率+0.7と評価し、史実でその年は−0.3 → 差し引き+0.4
     (実際の確認: 1988→89年の出生率は、政策なしで1.66→1.57、AIの評価+0.32があれば1.89)
   - 趨勢はAIに渡さない。AIには現在値と「開始時/前年比」だけを見せる。
     理由: 送るデータ量を減らし、AIの二重計上や混乱を避けるため。
   - 経済系の指標(GDP・債務など)には趨勢を入れていない。
   - 確認: 政策なしで30年進めると、指標が史実どおりに動く。
       バブル期: 出生率1.66→1.42、高齢化率11.2→28.2%
       現代:     出生率1.36→1.20、高齢化率17.3→30.8%
     (2024年以降は国立社会保障・人口問題研究所の将来推計などに基づく概数)

(C) 基準量とクリア条件の調整
1. 基準量(impact_unit)
   - 史実の趨勢で不利に動く8指標(出生率・総人口・高齢化率・生産年齢人口比率・婚姻率・
     医療費対GDP比・肥満率・食料自給率)は、政策で動かせる量を約1.3倍にした。
   - 犯罪発生率は、実際の件数に合わせて範囲を0〜4000、基準量を40に変更。
2. クリア条件を再調整(初期値・趨勢が変わったため。gpt-5.6-lunaの実出力を使ったモンテカルロ)
       バブル期: GDP560 / 成長率5.5 / 失業率1.0以下 / 債務430以下 / 満足度74 / 株価430 / 出生率2.1(人口置換水準)
       現代:     技術96 / デジタル化82 / 成長率3.5 / GDP560 / 満足度58 / 債務800以下 / 出生率1.8(政府の希望出生率)
   - 出生率の目標は、放置すると1.42(バブル期)や1.20(現代)まで下がる水準からの引き上げ。
   - 目安の勝率(熟練の反応型プレイヤー、政策の狙いが的確な割合0.5のとき): バブル期 約10% / 現代 約6.5%。
     狙いが的確な割合が0.35のとき約1%、0.7のとき約31〜39%。
   - 現代モードの途中ゲームオーバーは約16% → 約8%に減少。
