74 動く推移のグラフ(政策なしの線から実際の線へ)
===============================================

■ 基本情報
- コミット: 840fd9e
- 日付: 2026-10-17
- メッセージ: Animate trend charts from the no-policy path to the actual path

■ 概要
ユーザーの依頼「グラフに動きを取り入れたい。政策を取り入れなかった場合想定の推移グラフから、現在の各指標の推移グラフに上下する
ような感じに」を入れた(APIは使っていない)。

■ 変更内容
1. game/charts.py(新規): 動く推移のグラフの HTML。
   - 政策なしで進んだ場合の線(灰色の点線)を描き、実際の線は、はじめ政策なしの線の形で現れて、1.6秒かけて実際の値へ上下に
     動く(SVG の animate で線の形を変える。なめらかに減速する動き)。
   - 動き終わると、2本の線の間に色が付く(政策なしより良い向きなら緑、悪い向きなら赤。最後の年の値で決める)。最後の値の点と
     数字が現れる。目標は金の点線、今後の見込み(ダイアログ)は金の点線で続けて現れる。
   - 点にマウスを重ねると、その年の値と、政策なしの場合の値が出る。縦軸は値の範囲に合わせる(0からにしない)。
   - JavaScript を使わない(SVG のアニメーションだけ)。st.markdown は svg のタグを取り除くので、components.html で入れる。
   - 3列に並べる小さいグラフ(compact)は、縮んで表示されるので、文字を大きくし、目盛りを減らす。
2. app.py
   - 政策なしの道筋(_baseline_rows): 同じ乱数の種で、政策を1つも打たずに30年進めた毎年の値(出来事も同じ条件で起きる)。
     st.cache_data で覚えておく。
   - 任期の総括の国家目標の推移(6つ)・ほかの指標の推移と、指標のダイアログの推移のグラフを、動くグラフにした
     (以前の Altair のグラフはやめた)。
3. README を直した。

■ 確かめたこと
- アプリ内のブラウザ(?demo=start。保存しない確認用の表示)で、管理者のチートでダミーの30年を進め、任期の総括の6つのグラフと
  ほかの指標のグラフ、指標のダイアログのグラフを表示した。動きの途中(0.95秒)で止めて、実際の線が政策なしの線と実際の値の間に
  あること、動き終わったあとに2本の線の間の色(GDP・債務は緑、失業率は赤など)が付くことを確認した。
- 3列の小さいグラフの文字が読める大きさになったことを確認した。
